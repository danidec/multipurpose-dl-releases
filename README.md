# Multipurpose DL

A download manager for Windows: fast multi-connection downloads, YouTube and other video sites in up to 1080p,
pause and resume, batches, and a browser extension that sends downloads to the app.

## Download

**[Get the latest installer](https://github.com/danidec/multipurpose-dl-releases/releases/latest)**: under *Assets*, download `MultipurposeDL-Setup-<version>.exe` and run it.

- Windows 10 or 11 (64-bit). No admin rights needed.
- Windows may say **"Windows protected your PC"**, because the installer isn't code-signed. Click **More info**, then **Run anyway**.

## Updates

The app checks for new versions once a day and asks before installing one. It then updates itself and reopens.
You can turn the daily check off, or check by hand, under **Options > Updates**.

## Browser extension

After installing, open **Browser Extension Setup** from the Start menu. It explains how to add the extension to
Chrome, Edge, Brave and other Chromium browsers, and which browser profile to add it to.
